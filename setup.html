🎯 Automation Selector Picker

One quick setup step needed on Chrome

📌 Chrome macOS Note: Chrome on macOS requires you to manually assign keyboard shortcuts to extensions to avoid conflicts with system shortcuts. This is a Chrome limitation, not a bug!

1 Assign Your Keyboard Shortcut

  1. Copy this address: chrome://extensions/shortcuts
  2. Open a new tab and paste it into the address bar
  3. Find "Element Locator Picker" → "Toggle element locator picker"
  4. Click in the shortcut field and press: Cmd+Shift+L (Mac) or Ctrl+Shift+L (Windows)
  5. The shortcut is now assigned! ✅

2 Test Your Shortcut

  1. Visit any website
  2. Press Cmd+Shift+L (or Ctrl+Shift+L)
  3. You should see a crosshair cursor appear
  4. Click any element to get locators

💡 Alternative: Use the Quick Button

If you prefer not to set up a keyboard shortcut, click the extension icon anytime and select "Open picker now" to activate the picker instantly.

You can close this tab now. The extension is ready to use! 🚀
